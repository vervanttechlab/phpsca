The 3-Tier MVC Flow, One Sentence Each

  • Router (src/Core/Router.php) matches the URL and the HTTP method, then hands the request to a controller — PHP has no built-in equivalent, so this playbook writes one in about 60 lines.
  • Middleware (src/Middlewares) runs between the route and the controller to check the JWT token.
  • Controller (src/Controllers) holds the business logic and writes the SQL query, using PDO prepared statements.
  • Config (src/Config/Database.php) owns the one PDO connection every controller reuses for the request.
  • public/index.php is the front controller: every request that is not a static file lands here first.

Step 2. Autoloader & Database Connection

WHY THIS STEP NOWTwo things have to exist before any class can be written: a way for PHP to find your classes without a giant pile of require statements, and one shared way to reach MySQL. Both are small enough to write and trust immediately.
NEW FILEautoload.php — type the whole file. This sits at the project root, next to .env, not inside src/.
autoload.php
<?php

/**
 * A hand-written autoloader, standing in for Composer's vendor/autoload.php.
 * Vanilla PHP has no built-in autoloading, so every class file must be
 * required manually — or, once, here. Maps the App\ namespace onto the
 * src/ folder: App\Controllers\ItemController -> src/Controllers/ItemController.php
 */
spl_autoload_register(function (string $class): void {
    $prefix = 'App\\';
    if (!str_starts_with($class, $prefix)) {
        return;
    }
    $relative = substr($class, strlen($prefix));
    $path = __DIR__ . '/src/' . str_replace('\\', '/', $relative) . '.php';
    if (is_file($path)) {
        require $path;
    }
});
  • spl_autoload_register tells PHP "call this function whenever you hit a class name you don't recognize yet."
  • The namespace App\Controllers\ItemController maps onto the file path src/Controllers/ItemController.php — same convention Composer's PSR-4 autoloading uses, written by hand instead of generated.
  • This is the entire "dependency management" story for this project. There is no vendor/ folder because there is nothing to put in it.
NEW FILEsrc/Core/Env.php — type the whole file. This is PHP's stand-in for the dotenv package, and it has to exist before Database.php because Database.php reads the DB_* values through it.
src/Core/Env.php
<?php

namespace App\Core;

/**
 * Tiny .env loader. No Composer package, so this class is the entire
 * dependency: read KEY=VALUE lines and put them into the environment.
 */
class Env
{
    public static function load(string $path): void
    {
        if (!is_file($path)) {
            return;
        }

        foreach (file($path, FILE_IGNORE_NEW_LINES | FILE_SKIP_EMPTY_LINES) as $line) {
            $line = trim($line);
            if ($line === '' || str_starts_with($line, '#')) {
                continue;
            }
            [$key, $value] = array_pad(explode('=', $line, 2), 2, '');
            $key = trim($key);
            $value = trim($value);
            if ($key === '') {
                continue;
            }
            putenv("{$key}={$value}");
            $_ENV[$key] = $value;
        }
    }

    public static function get(string $key, ?string $default = null): ?string
    {
        $value = getenv($key);
        return $value === false ? $default : $value;
    }
}
  • PHP has no built-in .env reader. Env::load() does the one job require('dotenv').config() does in the Node edition: read KEY=VALUE lines and put them into the environment with putenv().
  • Env::get('DB_USER', 'root') returns the value from .env; the second argument is only a fallback when the key is missing. If you created the non-root tesda_app user on Day 1, this is what makes the API actually use it.
NEW FILEsrc/Config/Database.php — type the whole file.
src/Config/Database.php
<?php

namespace App\Config;

use App\Core\Env;
use PDO;
use PDOException;

/**
 * One shared PDO connection for the whole request, the same role
 * db.js's connection pool plays in the Node version. PHP does not need
 * a real pool the way Node does, since a fresh PHP process (and a
 * fresh PDO connection) is created per request by the web server —
 * this class just avoids opening the connection twice in one request.
 */
class Database
{
    private static ?PDO $connection = null;

    public static function getConnection(): PDO
    {
        if (self::$connection === null) {
            $host = Env::get('DB_HOST', 'localhost');
            $name = Env::get('DB_NAME', 'tesda_assessment_db');
            $user = Env::get('DB_USER', 'root');
            $pass = Env::get('DB_PASS', '');

            $dsn = "mysql:host={$host};dbname={$name};charset=utf8mb4";

            try {
                self::$connection = new PDO($dsn, $user, $pass, [
                    PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
                    PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
                ]);
            } catch (PDOException $e) {
                http_response_code(500);
                header('Content-Type: application/json');
                echo json_encode(['status' => 'error', 'message' => 'Database connection error: ' . $e->getMessage()]);
                exit;
            }
        }

        return self::$connection;
    }
}
  • PDO is PHP's own object-oriented database layer — no external package needed, unlike Node where mysql2 has to be installed.
  • PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION is what makes a bad query throw instead of silently returning false — without it, bugs go quiet.
  • The static $connection property means one PDO object per request, reused by every controller that calls Database::getConnection() — the PHP-appropriate equivalent of Node's connection pool. (A pool matters more in Node because one Node process serves many requests over time; PHP's built-in server and Apache/PHP-FPM both start a fresh process per request, so there is nothing to pool between requests — only within one.)

Step 4. Register Logic (src/Controllers/AuthController.php VERSION 1)

WHY THIS STEP NOWSame as the Node edition: write register in isolation first, so the only new idea is hashing a password before storing it.
NEW FILEsrc/Controllers/AuthController.php — VERSION 1, register only.
src/Controllers/AuthController.php (version 1)
<?php

namespace App\Controllers;

use App\Config\Database;
use App\Core\Request;
use App\Core\Response;

class AuthController
{
    // POST /api/v1/auth/register
    public function register(Request $request): void
    {
        $username = $request->body['username'] ?? null;
        $email = $request->body['email'] ?? null;
        $password = $request->body['password'] ?? null;

        if (!$username || !$email || !$password) {
            Response::error('All fields are required.', 400);
        }

        $db = Database::getConnection();

        $stmt = $db->prepare('SELECT id FROM users WHERE email = ? OR username = ?');
        $stmt->execute([$email, $username]);

        if ($stmt->fetch() !== false) {
            Response::error('Username or email already in use.', 400);
        }

        $hashedPassword = password_hash($password, PASSWORD_BCRYPT);

        $stmt = $db->prepare('INSERT INTO users (username, email, password) VALUES (?, ?, ?)');
        $stmt->execute([$username, $email, $hashedPassword]);

        Response::success([
            'message' => 'User registered successfully.',
            'userId' => (int) $db->lastInsertId(),
        ], 201);
    }
}

Points the assessor listens for — and where PHP is genuinely simpler than Node here:

  • The ? placeholders are prepared-statement placeholders, exactly like mysql2's — still what stops SQL injection.
  • password_hash($password, PASSWORD_BCRYPT) is a PHP core function. There is no bcryptjs to install: hashing a password needs zero external packages in PHP.
  • Response::error() calls exit internally, so it behaves like Node's return res.status(400).json(...) — execution stops right there, nothing below it runs.

There is nothing to run yet — this function has no Request object being built for it and no URL routed to it. That is Step 5.

Step 5. Router, Request & Wiring Register (index.php VERSION 2)

WHY THIS STEP NOWThis is where register finally becomes reachable. Three small pieces: a Request object a controller can read, a Router that matches method+path to a controller method, and two lines in index.php that wire it all together.
NEW FILEsrc/Core/Request.php — type the whole file.
src/Core/Request.php
<?php

namespace App\Core;

/**
 * Bundles the three things a controller ever needs to read, matching
 * the Express req object: route params (req.params), the query string
 * (req.query), and the parsed JSON body (req.body). $user is filled in
 * by AuthMiddleware, the same way req.user is filled in by the Node
 * middleware, and is null until a route runs the middleware.
 */
class Request
{
    public array $params;
    public array $query;
    public array $body;
    public ?array $user = null;

    public function __construct(array $params = [])
    {
        $this->params = $params;
        $this->query = $_GET;
        $this->body = self::parseJsonBody();
    }

    public function header(string $name): ?string
    {
        $key = 'HTTP_' . strtoupper(str_replace('-', '_', $name));
        return $_SERVER[$key] ?? null;
    }

    private static function parseJsonBody(): array
    {
        $raw = file_get_contents('php://input');
        if ($raw === false || $raw === '') {
            return [];
        }
        $decoded = json_decode($raw, true);
        return is_array($decoded) ? $decoded : [];
    }
}
NEW FILEsrc/Core/Router.php — type the whole file.
src/Core/Router.php
<?php

namespace App\Core;

/**
 * A deliberately small router: register method+pattern pairs, then
 * dispatch one request. Patterns use :name for a single path segment,
 * e.g. '/api/v1/items/:id'. Routes are matched in registration order,
 * top to bottom — same rule as Express, which is why /summary must
 * still be registered before /:id.
 */
class Router
{
    private array $routes = [];

    public function get(string $pattern, callable $handler, array $middlewares = []): void
    {
        $this->add('GET', $pattern, $handler, $middlewares);
    }

    public function post(string $pattern, callable $handler, array $middlewares = []): void
    {
        $this->add('POST', $pattern, $handler, $middlewares);
    }

    public function put(string $pattern, callable $handler, array $middlewares = []): void
    {
        $this->add('PUT', $pattern, $handler, $middlewares);
    }

    public function delete(string $pattern, callable $handler, array $middlewares = []): void
    {
        $this->add('DELETE', $pattern, $handler, $middlewares);
    }

    private function add(string $method, string $pattern, callable $handler, array $middlewares): void
    {
        $this->routes[] = compact('method', 'pattern', 'handler', 'middlewares');
    }

    public function dispatch(string $method, string $uri): void
    {
        $path = parse_url($uri, PHP_URL_PATH);

        foreach ($this->routes as $route) {
            if ($route['method'] !== $method) {
                continue;
            }
            $params = $this->match($route['pattern'], $path);
            if ($params === null) {
                continue;
            }

            $request = new Request($params);
            foreach ($route['middlewares'] as $middleware) {
                $middleware($request);
            }
            ($route['handler'])($request);
            return;
        }

        Response::error('Endpoint Not Found', 404);
    }

    /** Returns an array of named params on match, or null if this pattern does not match. */
    private function match(string $pattern, string $path): ?array
    {
        $patternParts = explode('/', trim($pattern, '/'));
        $pathParts = explode('/', trim($path, '/'));

        if (count($patternParts) !== count($pathParts)) {
            return null;
        }

        $params = [];
        foreach ($patternParts as $i => $part) {
            if (str_starts_with($part, ':')) {
                $params[substr($part, 1)] = $pathParts[$i];
            } elseif ($part !== $pathParts[$i]) {
                return null;
            }
        }
        return $params;
    }
}

Step 6. Login & JWT (AuthController VERSION 2)

WHY THIS STEP NOWYou have a user but no way to prove who you are on the next request. Login checks the password and issues a signed token, exactly like the Node edition's jsonwebtoken step — except this playbook writes the token library itself, in about 40 lines, since vanilla PHP ships no JWT support.
NEW FILEsrc/Core/Jwt.php — type the whole file.
src/Core/Jwt.php
<?php

namespace App\Core;

/**
 * A minimal HS256 JWT: header.payload.signature, base64url-encoded,
 * signed with hash_hmac. No Composer package — this is the whole library.
 * Same shape as the jsonwebtoken version: header {alg, typ}, payload
 * carries id/username/role plus an exp claim, signature is HMAC-SHA256.
 */
class Jwt
{
    public static function encode(array $payload, string $secret, int $expiresInSeconds = 7200): string
    {
        $header = ['alg' => 'HS256', 'typ' => 'JWT'];
        $payload['iat'] = time();
        $payload['exp'] = time() + $expiresInSeconds;

        $segments = [
            self::base64UrlEncode(json_encode($header)),
            self::base64UrlEncode(json_encode($payload)),
        ];

        $signature = hash_hmac('sha256', implode('.', $segments), $secret, true);
        $segments[] = self::base64UrlEncode($signature);

        return implode('.', $segments);
    }

    /**
     * Returns the decoded payload array on success, or null on any
     * failure: malformed token, bad signature, or expired.
     */
    public static function decode(string $token, string $secret): ?array
    {
        $parts = explode('.', $token);
        if (count($parts) !== 3) {
            return null;
        }
        [$headerB64, $payloadB64, $signatureB64] = $parts;

        $expectedSignature = hash_hmac('sha256', "{$headerB64}.{$payloadB64}", $secret, true);
        $actualSignature = self::base64UrlDecode($signatureB64);

        if (!hash_equals($expectedSignature, $actualSignature)) {
            return null;
        }

        $payload = json_decode(self::base64UrlDecode($payloadB64), true);
        if (!is_array($payload)) {
            return null;
        }

        if (isset($payload['exp']) && time() >= $payload['exp']) {
            return null;
        }

        return $payload;
    }

    private static function base64UrlEncode(string $data): string
    {
        return rtrim(strtr(base64_encode($data), '+/', '-_'), '=');
    }

    private static function base64UrlDecode(string $data): string
    {
        $padded = str_pad($data, strlen($data) % 4 === 0 ? strlen($data) : strlen($data) + (4 - strlen($data) % 4), '=');
        return base64_decode(strtr($padded, '-_', '+/'));
    }
}
  • A JWT is just three base64url pieces joined by dots: header, payload, signature. hash_hmac('sha256', ..., $secret, true) is PHP's built-in HMAC-SHA256 — the same algorithm jsonwebtoken uses under HS256, just called directly instead of through a library.
  • hash_equals() instead of === for comparing signatures matters: it runs in constant time, so an attacker cannot use response-time differences to guess the correct signature one byte at a time (a timing attack).
  • The exp claim is checked inside decode() itself — an expired token fails verification the same way a tampered one does, both simply return null.

<?php

namespace App\Middlewares;

use App\Core\Env;
use App\Core\Jwt;
use App\Core\Request;
use App\Core\Response;

/**
 * Verifies "Authorization: Bearer <token>" the same way src/middlewares/auth.js
 * does in the Node version: no header at all is 401, a header that fails
 * to verify is 403, and on success the decoded payload is attached to
 * the request as $request->user so the controller knows who is calling.
 */
class AuthMiddleware
{
    public function __invoke(Request $request): void
    {
        $header = $request->header('Authorization');
        $token = null;
        if ($header !== null) {
            $parts = explode(' ', $header);
            $token = $parts[1] ?? null;
        }

        if (!$token) {
            Response::error('Access Denied: No Token Provided', 401);
        }

        $payload = Jwt::decode($token, Env::get('JWT_SECRET', 'fallback_secret'));

        if ($payload === null) {
            Response::error('Invalid or Expired Token', 403);
        }

        $request->user = $payload;
    }
}
  • No token at all is 401 — the caller never identified itself.
  • A token that fails to decode (bad signature, or expired) is 403 — same status split as the Node edition.
  • On success, $request->user is filled in, the PHP equivalent of Node's req.user, and the Router's dispatch() method (written back in Step 5) is what actually calls this middleware before the controller, for any route registered with it as a third argument.

    public function create(Request $request): void
    {
        $title = $request->body['title'] ?? null;
        $description = $request->body['description'] ?? '';
        $price = $request->body['price'] ?? null;
        $categoryId = $request->body['category_id'] ?? null;

            $db->beginTransaction();

            $stmt = $db->prepare(
                'INSERT INTO items (title, description, price, category_id, user_id) VALUES (?, ?, ?, ?, ?)'
            );
            $stmt->execute([$title, $description, $price, $categoryId, $userId]);
            $newItemId = (int) $db->lastInsertId();

            $stmt = $db->prepare('INSERT INTO activity_logs (user_id, action) VALUES (?, ?)');
            $stmt->execute([$userId, "Created item #{$newItemId}: \"{$title}\""]);

            $db->commit();

            Response::success([
                'message' => 'Item created and activity logged successfully via Database Transaction.',
                'itemId' => $newItemId,
            ], 201);
        } catch (Throwable $e) {
            $db->rollBack();
            Response::error($e->getMessage(), 500);
        }
    }

What the new pieces do, and how each maps back to the Node edition:

  • header('X-Content-Type-Options: nosniff'), X-Frame-Options and a Content-Security-Policy header are hand-written here because vanilla PHP has no helmet() — these are the same headers helmet sets by default, just spelled out one header() call at a time.
  • The three Access-Control-Allow-* headers are what cors() does automatically in Node; PHP needs them written explicitly, plus a short-circuit for the OPTIONS preflight request browsers send before certain cross-origin calls.
  • The 404 lives inside Router::dispatch() itself (Step 5) as the fallback when nothing matches — the PHP equivalent of Express's catch-all middleware registered after every route.
  • The try/catch (Throwable $e) wrapped around $router->dispatch() is the one global error handler: anything a controller does not catch itself lands here as a generic 500, the same safety net Express's four-argument error handler provides.

    // GET /api/v1/items?search=&category_id=&min_price=&max_price=
    public function getAll(Request $request): void
    {
        $db = Database::getConnection();

        $sql = "
            SELECT
                i.id, i.title, i.description, i.price, i.created_at,
                c.name AS category_name,
                u.username AS author_name,
                u.email AS author_email
            FROM items i
            INNER JOIN users u ON i.user_id = u.id
            LEFT JOIN categories c ON i.category_id = c.id
            WHERE 1=1
        ";
        $params = [];

        if (!empty($request->query['search'])) {
            $sql .= ' AND i.title LIKE ?';
            $params[] = '%' . $request->query['search'] . '%';
        }
        if (!empty($request->query['category_id'])) {
            $sql .= ' AND i.category_id = ?';
            $params[] = $request->query['category_id'];
        }
        if (!empty($request->query['min_price'])) {
            $sql .= ' AND i.price >= ?';
            $params[] = $request->query['min_price'];
        }
        if (!empty($request->query['max_price'])) {
            $sql .= ' AND i.price <= ?';
            $params[] = $request->query['max_price'];
        }

        $sql .= ' ORDER BY i.created_at DESC';

        $stmt = $db->prepare($sql);
        $stmt->execute($params);
        $items = $stmt->fetchAll();

        Response::success(['count' => count($items), 'data' => $items]);
    }

Memory Tips & Common Errors

PDO Transactions (vs. mysql2)

  • No separate connection to acquire: $db = Database::getConnection(); is already the one connection for this request.
  • Start it: $db->beginTransaction();
  • On success: $db->commit();
  • On error: $db->rollBack(); (capital B — a common typo).
  • No release() call exists or is needed — the connection closes when the PHP request ends.

SQL Joins & Aggregation

Unchanged from the Node edition: INNER JOIN needs a match in both tables; LEFT JOIN keeps every left-side row and fills missing right-side columns with null; HAVING filters after GROUP BY, WHERE cannot because it runs before grouping.

Direct answer: "Yes, I structured it using MVC, in plain object-oriented PHP with no framework."

"Model is the data layer: database/schema.sql defines the tables, src/Config/Database.php holds the one PDO connection, and the queries live inside each Controller using prepared statements. <?php

namespace App\Controllers;

use App\Config\Database;
use App\Core\Env;
use App\Core\Jwt;
use App\Core\Request;
use App\Core\Response;
use PDO;

class AuthController
{
    // POST /api/v1/auth/register
    public function register(Request $request): void
    {
        $username = $request->body['username'] ?? null;
        $email = $request->body['email'] ?? null;
        $password = $request->body['password'] ?? null;

        if (!$username || !$email || !$password) {
            Response::error('All fields are required.', 400);
        }

        $db = Database::getConnection();

        $stmt = $db->prepare('SELECT id FROM users WHERE email = ? OR username = ?');
        $stmt->execute([$email, $username]);

        if ($stmt->fetch() !== false) {
            Response::error('Username or email already in use.', 400);
        }

        $hashedPassword = password_hash($password, PASSWORD_BCRYPT);

        $stmt = $db->prepare('INSERT INTO users (username, email, password) VALUES (?, ?, ?)');
        $stmt->execute([$username, $email, $hashedPassword]);

        Response::success([
            'message' => 'User registered successfully.',
            'userId' => (int) $db->lastInsertId(),
        ], 201);
    }

    // POST /api/v1/auth/login
    public function login(Request $request): void
    {
        $email = $request->body['email'] ?? null;
        $password = $request->body['password'] ?? null;

        if (!$email || !$password) {
            Response::error('Email and password are required.', 400);
        }

        $db = Database::getConnection();
        $stmt = $db->prepare('SELECT * FROM users WHERE email = ?');
        $stmt->execute([$email]);
        $user = $stmt->fetch();

        if ($user === false) {
            Response::error('Invalid credentials.', 401);
        }

        if (!password_verify($password, $user['password'])) {
            Response::error('Invalid credentials.', 401);
        }

        $payload = ['id' => (int) $user['id'], 'username' => $user['username'], 'role' => $user['role']];
        $token = Jwt::encode($payload, Env::get('JWT_SECRET', 'fallback_secret'), 7200);

        Response::success([
            'message' => 'Login successful.',
            'token' => $token,
        ]);
    }
}

<?php

namespace App\Controllers;

use App\Config\Database;
use App\Core\Request;
use App\Core\Response;
use Throwable;

class ItemController
{
    // GET /api/v1/items?search=&category_id=&min_price=&max_price=
    public function getAll(Request $request): void
    {
        $db = Database::getConnection();

        $sql = "
            SELECT
                i.id, i.title, i.description, i.price, i.created_at,
                c.name AS category_name,
                u.username AS author_name,
                u.email AS author_email
            FROM items i
            INNER JOIN users u ON i.user_id = u.id
            LEFT JOIN categories c ON i.category_id = c.id
            WHERE 1=1
        ";
        $params = [];

        if (!empty($request->query['search'])) {
            $sql .= ' AND i.title LIKE ?';
            $params[] = '%' . $request->query['search'] . '%';
        }
        if (!empty($request->query['category_id'])) {
            $sql .= ' AND i.category_id = ?';
            $params[] = $request->query['category_id'];
        }
        if (!empty($request->query['min_price'])) {
            $sql .= ' AND i.price >= ?';
            $params[] = $request->query['min_price'];
        }
        if (!empty($request->query['max_price'])) {
            $sql .= ' AND i.price <= ?';
            $params[] = $request->query['max_price'];
        }

        $sql .= ' ORDER BY i.created_at DESC';

        $stmt = $db->prepare($sql);
        $stmt->execute($params);
        $items = $stmt->fetchAll();

        Response::success(['count' => count($items), 'data' => $items]);
    }

    // POST /api/v1/items  (Create Item inside an ACID Database Transaction)
    public function create(Request $request): void
    {
        $title = $request->body['title'] ?? null;
        $description = $request->body['description'] ?? '';
        $price = $request->body['price'] ?? null;
        $categoryId = $request->body['category_id'] ?? null;
        $userId = $request->user['id'] ?? null;

        if (!$title || $price === null) {
            Response::error('Title and price are required.', 400);
        }

        $db = Database::getConnection();

        try {
            $db->beginTransaction();

            $stmt = $db->prepare(
                'INSERT INTO items (title, description, price, category_id, user_id) VALUES (?, ?, ?, ?, ?)'
            );
            $stmt->execute([$title, $description, $price, $categoryId, $userId]);
            $newItemId = (int) $db->lastInsertId();

            $stmt = $db->prepare('INSERT INTO activity_logs (user_id, action) VALUES (?, ?)');
            $stmt->execute([$userId, "Created item #{$newItemId}: \"{$title}\""]);

            $db->commit();

            Response::success([
                'message' => 'Item created and activity logged successfully via Database Transaction.',
                'itemId' => $newItemId,
            ], 201);
        } catch (Throwable $e) {
            $db->rollBack();
            Response::error($e->getMessage(), 500);
        }
    }

    // GET /api/v1/items/:id  (Read One)
    public function getOne(Request $request): void
    {
        $db = Database::getConnection();
        $stmt = $db->prepare("
            SELECT
                i.id, i.title, i.description, i.price, i.created_at,
                c.name AS category_name,
                u.username AS author_name
            FROM items i
            INNER JOIN users u ON i.user_id = u.id
            LEFT JOIN categories c ON i.category_id = c.id
            WHERE i.id = ?
        ");
        $stmt->execute([$request->params['id']]);
        $item = $stmt->fetch();

        if ($item === false) {
            Response::error('Item not found.', 404);
        }

        Response::success(['data' => $item]);
    }

    // GET /api/v1/items/summary  (Analytics with GROUP BY, HAVING, ORDER BY)
    public function summary(Request $request): void
    {
        $db = Database::getConnection();
        $stmt = $db->query("
            SELECT
                c.id AS category_id,
                c.name AS category_name,
                COUNT(i.id) AS total_items,
                AVG(i.price) AS average_price,
                MAX(i.price) AS max_price
            FROM categories c
            LEFT JOIN items i ON c.id = i.category_id
            GROUP BY c.id, c.name
            HAVING total_items > 0
            ORDER BY average_price DESC
        ");
        $summary = $stmt->fetchAll();

        Response::success(['count' => count($summary), 'data' => $summary]);
    }

    // PUT /api/v1/items/:id  (Update)
    public function update(Request $request): void
    {
        $db = Database::getConnection();
        $stmt = $db->prepare('
            UPDATE items SET
                title = COALESCE(?, title),
                description = COALESCE(?, description),
                price = COALESCE(?, price),
                category_id = COALESCE(?, category_id)
            WHERE id = ?
        ');
        $stmt->execute([
            $request->body['title'] ?? null,
            $request->body['description'] ?? null,
            $request->body['price'] ?? null,
            $request->body['category_id'] ?? null,
            $request->params['id'],
        ]);

        if ($stmt->rowCount() === 0) {
            Response::error('Item not found or no changes made.', 404);
        }

        Response::success(['message' => 'Item updated successfully.']);
    }

    // DELETE /api/v1/items/:id
    public function delete(Request $request): void
    {
        $db = Database::getConnection();
        $stmt = $db->prepare('DELETE FROM items WHERE id = ?');
        $stmt->execute([$request->params['id']]);

        if ($stmt->rowCount() === 0) {
            Response::error('Item not found.', 404);
        }

        Response::success(['message' => 'Item deleted successfully.']);
    }
}

<?php

// public/index.php - FINAL (front controller)
require __DIR__ . '/../autoload.php';

use App\Controllers\AuthController;
use App\Controllers\ItemController;
use App\Core\Env;
use App\Core\Response;
use App\Core\Router;
use App\Middlewares\AuthMiddleware;

Env::load(__DIR__ . '/../.env');

// Security headers, hand-rolled (this is what helmet() does in the Node version)
header('X-Content-Type-Options: nosniff');
header('X-Frame-Options: DENY');
header("Content-Security-Policy: default-src 'self'");

// CORS, hand-rolled (this is what cors() does in the Node version)
header('Access-Control-Allow-Origin: *');
header('Access-Control-Allow-Headers: Content-Type, Authorization, x-api-key');
header('Access-Control-Allow-Methods: GET, POST, PUT, DELETE, OPTIONS');
if ($_SERVER['REQUEST_METHOD'] === 'OPTIONS') {
    http_response_code(204);
    exit;
}

$requestUri = $_SERVER['REQUEST_URI'];
$requestPath = parse_url($requestUri, PHP_URL_PATH);

// Health check, before routing and before the static file check below
if ($requestPath === '/') {
    Response::json([
        'status' => 'online',
        'message' => 'TESDA NC III Backend API Server Running (PHP)',
        'version' => 'v1.0.0',
    ]);
}

// Serve the public/ folder's own static files (e.g. /items.html) directly,
// the same role express.static() plays in the Node version.
$staticFile = __DIR__ . $requestPath;
if ($requestPath !== '/' && is_file($staticFile)) {
    return false; // let the PHP built-in server / Apache serve it as-is
}

$router = new Router();
$authMiddleware = new AuthMiddleware();
$auth = new AuthController();
$items = new ItemController();

$router->post('/api/v1/auth/register', [$auth, 'register']);
$router->post('/api/v1/auth/login', [$auth, 'login']);

$router->get('/api/v1/items', [$items, 'getAll']);
$router->get('/api/v1/items/summary', [$items, 'summary']); // must stay above /:id
$router->get('/api/v1/items/:id', [$items, 'getOne']);
$router->post('/api/v1/items', [$items, 'create'], [$authMiddleware]);
$router->put('/api/v1/items/:id', [$items, 'update'], [$authMiddleware]);
$router->delete('/api/v1/items/:id', [$items, 'delete'], [$authMiddleware]);

try {
    $router->dispatch($_SERVER['REQUEST_METHOD'], $requestUri);
} catch (Throwable $e) {
    error_log('Server Error: ' . $e->getMessage());
    Response::error('Internal Server Error', 500);
}
